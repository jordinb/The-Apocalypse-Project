# The Apocalypse Project resources

Start the complete map with one line:

ensure [the_apocalypse_project]

Resources are split only for testing and controlled rollout. pocalypse-core loads shared archetypes first; the other resources depend on it.

- pocalypse-los-santos — city, casino, industrial, and downtown destruction
- pocalypse-blaine — Paleto, mine, county improvements, and motel
- pocalypse-infrastructure — roads, highways, barriers, bridges, metro, and tunnels
- pocalypse-statewide — mixed-region, landmark, and wilderness map packs
- pocalypse-interiors — interior YTYP definitions
